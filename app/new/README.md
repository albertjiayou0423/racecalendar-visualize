# 独立新版首页 /new

新版页面、样式、浏览器选择记忆和数据适配均放在本目录。旧首页仅在 `components/schedule-view.tsx` 增加 `NewHomeEntry` 胶囊、介绍弹窗及偏好跳转；旧首页原组件、列表、筛选和业务请求保持原样。Playground 不挂载新版入口。

## 版本选择

- 直接访问 `/new` 或从旧首页进入新版后，在当前浏览器保存 `racecalendar-home-version=new`，之后访问 `/` 使用客户端替换导航到 `/new`。
- 新版顶栏和页脚都可返回 `/?home=classic`，将偏好保存为 `classic`。这个查询参数也能在存储不可用时阻止旧首页再次重定向。
- 其他路由不参与偏好跳转。存储被禁用时仍能正常导航，只是不保证下次自动进入新版。
- 旧版介绍自动提示一次，并避开已打开的新手指南或其他模态窗；胶囊可随时重开介绍。新版保留轻量欢迎条，可手动收起。

## 数据与交互

复用 `/api/schedule`、现有按系列浏览器缓存合并函数和 `schedule-cache-v2`，网络失败明确显示离线，部分失败保留成功系列的上次数据及来源信息。不新增外部数据源、爬虫、数据库写入或轮询。

首屏按真实 UTC 选择当前系列和搜索范围内最近的未来已确认场次，不以主赛时间代替最近场次。估计、无效或未经核验的客户端时间不生成精确倒计时；列表保留待确认提示。日期带按北京时间分日，计数是赛事数量，同一站多个场次不重复计数。

列表覆盖未来和安排未公布的赛事，展开后查看完整场次，可前往既有赛事详情。日期带只筛选下方列表，首屏继续显示最近场次。搜索和系列筛选同时作用于首屏与列表。

沉浸入口复用真实 F1/FE 倒计时与 WRC 连续赛段组件。自动进入复用既有候选规则及 sessionStorage 抑制键，在两分钟窗口触发、避开其他模态窗，关闭后不重复打扰。WRC 仍仅最早赛段自动触发。页面隐藏时停止本页计时更新。

样式限定在 `.new-home` 下；手机自适应、键盘焦点、弹窗焦点限制、Esc 退出和系统减少动态效果均保留。未改动全局引导、Service Worker 或其他路由。

## 验证

`node --test app/new/home.test.mjs` 检查偏好、待定数据、最近场次、北京时间边界与缓存回退。全仓库检查仍运行 `pnpm exec tsc --noEmit`、`pnpm test`、`pnpm build`。本地 UI QA 使用隔离赛历响应，避免普通界面测试触发线上数据库/采集。隔离数据不进入正式页面或提交。
