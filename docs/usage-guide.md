# v2.2.1 使用指南

公开页面首次访问约 600 毫秒后显示界面选择菜单，可选择首页、赛事卡片、赛事详情、积分榜、历史赛果、壁纸与赛道数据库指南。选择页面指南后跳转到对应页面并开始高亮讲解。背景变暗，实际按钮或区域被框出，旁边说明用途；支持上一步、下一步、跳过与完成。首页介绍搜索、筛选和视图，然后进入真实赛事卡片，赛事详情、积分榜、历史赛果、壁纸、赛道数据库与更新页分别介绍自己的控件。后台不自动打开引导。

步骤与目标选择器集中在 `lib/usage-guide.ts`，组件通过 `data-guide` 等稳定标记定位。切换步骤时自动滚动到目标，并在滚动、窗口缩放和 DOM 更新后重新测量。目标缺失或隐藏超过 1200 毫秒会跳过；提示位置根据视口和面板高度计算，手机上限制面板宽高并允许内部滚动。

浏览器 localStorage 的 `racecalendar:usage-guide-seen=1` 记录已展示状态，不随应用版本重置；关闭、跳过或完成后不再自动出现。同一设备的其他浏览器、无痕窗口或清除站点数据后视为新访问。存储不可用时仅在当前页面会话中避免重复展示。

首页底部“使用指南”胶囊和其他公开页面右下角入口可随时重开选择菜单。手动打开会取消待执行的自动打开，不修改筛选。弹窗使用原生 dialog 管理焦点与 Escape 关闭，打开时阻止背景滚动及首页键盘快捷键。

当前测试使用模拟 React 生命周期验证首次访问、持久化、手动打开和后台排除逻辑，同时检查各页面步骤及手机、桌面视口的提示位置边界；不代替实际浏览器的布局、焦点与触屏验证。

赛事卡片指南直接定位首页当前列表最上面的真实卡片，不生成虚构赛程或使用 emoji。场次步骤会展开卡片与首个日期；不存在的可选功能会跳过。进入卡片指南时切换到列表视图，保留现有筛选；无赛事时不制造示例。底部胶囊不列入讲解。

## 关注与观赛功能

指南选择菜单邀请用户选择 F1、WRC、Formula E；改动即时同步首页关注设置。可跳过，之后可在首页修改。全站偏好只保存在本机浏览器。周末清单、日历订阅、数据更新时间与防剧透入口可在主界面直接操作。
