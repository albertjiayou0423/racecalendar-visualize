# v2.2.1 使用指南

公开页面首次访问约 600 毫秒后显示八步使用指南，涵盖首页赛历、赛事详情、积分榜、历史赛果、壁纸、赛道数据库和底部入口。后台不自动打开引导。

浏览器 localStorage 的 `racecalendar:usage-guide-seen=1` 记录已展示状态，不随应用版本重置；关闭、跳过或完成后不再自动出现。同一设备的其他浏览器、无痕窗口或清除站点数据后视为新访问。存储不可用时仅在当前页面会话中避免重复展示。

首页底部“使用指南”胶囊和其他公开页面右下角入口可随时从第一步重开。手动打开会取消待执行的自动打开，不修改筛选。弹窗使用原生 dialog 管理焦点与 Escape 关闭，打开时阻止背景滚动及首页键盘快捷键。

当前测试使用模拟 React 生命周期验证首次访问、持久化、手动打开和后台排除逻辑，不代替实际浏览器的布局、焦点与触屏验证。
