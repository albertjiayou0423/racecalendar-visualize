# Playground 组件 Cheatsheet

`/playground` 会枚举组件目录中的全部 38 个导出组件，每个组件单独一行：左侧加载该组件的正式实现，右侧编辑 props；手机上按先预览、后参数排列。顶部索引和搜索可定位组件。

每行右侧的胶囊只控制这一行。大多数组件有“默认、变体、边界”三套真实 props；没有公开 props 的组件提供“默认、手机、减少动态”视口预设。修改字段或完整 JSON props 后，左侧通过同源 `postMessage` 实时更新，不重载 iframe。事件、数组和其它嵌套 props 可以在折叠对象字段或完整 JSON 编辑器中调整。函数回调由宿主记录，不能序列化编辑。每行也有独立视口宽高、动效时长、曲线和减少动态效果设置。

目录覆盖所有具名 UI 导出：Button、赛事卡片/详情与倒计时组件、日历视图、积分图表、天气/计时/赛道图片、壁纸和分享组件、预测、提醒、反馈、指南、后台与辅助组件。无界面的 ClientCrawl、SWRegister 仍单独列出，并说明没有可视预览；PlaygroundPreview 宿主自身展示说明，避免递归嵌套。内部 Context、hook 和 buttonVariants 是状态/样式工具，不是独立 UI 组件。

赛事与会话使用 `playground-` 样例数据；场次时间按稳定 UTC ISO 值构造。没有外部连接的数据组件会保留真实加载、失败或空态。预览响应的 Content-Security-Policy 将连接和图片来源限制到本站、禁用 worker 和表单提交；预览页的 fetch 保护继续放行 Next 页面载入，同时拦截 `/api/` 和外网请求。另隔离页面链接导航、服务工作线程、系统通知和用户指南持久化。通知在预览中只切换组件本地状态；Feedback 与 Admin 的服务端请求不会抵达接口。某字段 JSON 暂时不合法时，保留最近一次有效 props 并显示提示。

通过现有 React Context 让需要隔离的正式组件读取样例时间/数据或停止外部副作用。预览始终渲染导出的真实组件实现，没有重写一份展示版组件。组件索引在单一目录函数维护；新增组件时，为它登记真实导出、默认/变体/边界输入与动态加载器，并检查两个清单一致。
