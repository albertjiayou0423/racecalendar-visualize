# Playground 真实组件预览

入口 `/playground`。iframe 的 `/playground/preview` 直接导入正式 ScheduleView、EventCard、WeekView、MonthView、FeedbackButton、NextRacePreview 与 ImmersiveCountdown；没有另写展示版卡片或倒计时。撒花和提示音使用正式 countdown-hooks。

宽度可选 320 / 375 / 390 / 768 / 1024px。独立视口会真实触发响应式断点；外层容器横向滚动，避免将桌面组件缩放冒充手机布局。过渡时长、曲线、减少动态效果仅影响预览文档，不保存或影响正式页面。

正常、加载、空数据、错误、离线、待确认、长名称、密集场次采用独立确定性场景。加载/空数据/错误/离线沿用 ScheduleView 的实际状态布局；其他组件本身没有这些状态时，使用真实首页状态作为参考，并不伪造不存在的组件变体。

倒计时支持 0–172800 秒、阶段快捷定位与开始/暂停/重置。阶段显示和沉浸式弹层来自真实组件；预览不自动播放倒计时提示音，试听通过明确点击完成。减少动态效果关闭预览动画与撒花；系统设置仍由正式特效尊重。

隔离：Playground 路由不运行 ClientCrawl；预览 ScheduleView 禁用真实 SWR 请求及赛历缓存读取，不启动通知或上站回顾，不挂载预测投票。WeatherCard / LiveTiming 在预览中使用实际错误提示区说明不请求外部数据。反馈使用真实表单校验，合法表单也不会 POST，显示“未提交任何反馈”。导航链接显示其目标，预览视口不离开测试台。iframe 不显示全局使用指南。

这是 UI 测试台，不代表生产数据或外部接口成功。测试事件带 playground- 前缀，不能写入数据库；未新增管理接口、生产写入或部署配置。

本地验收：99 项测试通过；浏览器检查了真实空态、失败、离线、待确认 WRC 展开、周/月历、反馈阻止提交、弹层 Esc、超过一天的倒计时与减少动态效果。320px 卡片预览实际宽度与滚动宽度相同（319px）；外层手机测试同样无页面溢出。开发日志没有赛历、天气或其他业务 API 请求。

完整类型检查仍被基线的损坏 circuit-db.ts 阻塞；排除该文件的辅助检查仍存在原有 Lucide title、可选图片和 LiveTiming 收窄错误，不能宣称完整类型检查通过。构建使用现有 ignoreBuildErrors 配置，与类型检查分别报告。
