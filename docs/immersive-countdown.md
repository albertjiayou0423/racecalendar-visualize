# 沉浸式开赛倒计时

视觉使用扁平化设计：纯色灯板与信号、细边框、点阵数字。允许亮灯与点阵的少量柔和光晕；不使用渐变外壳、立体阴影或透视，不再画模拟车辆或赛道路线。

首页可见时，已确认场次距开始 0–30 秒（不包含归零）自动覆盖进入倒计时，适用于全部系列与首页视图。WRC 每站只允许时间最早的有效赛段自动触发：先按时间选第一段，再判断时间确认状态与触发窗口，不会在第一段过去后改为自动弹出后续段。忽略无效、估计、客户端待核验时间；有其他模态窗口时等待。多个场次选最近开赛者，不受首页筛选影响。

赛事详情时间线中，每个有有效且非估计时间的 WRC 赛段均提供手动倒计时按钮；待定赛段不虚构倒计时。

自动进入采用 1.25 秒的自下向上波浪转场，波浪离场后露出计时画面，关闭按钮始终可用。移动端粗指针设备尝试短震 35 毫秒；浏览器不支持、限制震动或没有用户激活时静默降级。减少动态效果模式不播放波浪也不震动。手动进入不触发该自动入场震动。

进入后保留该场次，不随首页下一场目标变化。sessionStorage 按赛事 ID 与 UTC 记录本标签页已展示场次，关闭、刷新后不重复弹出；存储不可用时使用内存记录。后台标签页不触发，回到首页可见时重新判断。离开首页不显示。

数字使用 NumberFlow 按位滚动，长倒计时拆分天、小时、分钟、秒；分钟与秒的十位限制为 5。最后五秒只显示秒。减少动态效果偏好由库默认尊重。

起跑装置仅在最后 30 分钟显示。F1 五列四灯位，下方两红灯成对亮起；FE 上下两排五灯，下排红灯，上排辅助绿灯。最后五秒逐列点亮红灯，归零熄灯。已删除暖胎圈时长推算、蓝色预启动程序和程序演示按钮，不再自动播放模拟发车程序。自动进入只发生在赛程开始前 30 秒。

WRC 按墨西哥站实拍的左右分区计时板布局：左侧圆形秒针与当地时钟，右侧黄绿色点阵剩余时间；最后一分钟显示无前导零的秒数，之前使用分:秒。归零变绿仅表示赛程时间已到。板外不重复显示数字；超过半小时继续使用天、小时、分钟、秒的通用倒计时。各站计时硬件不同，这不是所有 WRC 站点的统一设备，也不是特定车手实际发车信号。

F1 实时状态来自 `/api/f1-start`，详见 `docs/data-flow.md`。明确 FORMATION LAP 消息显示辅助绿灯（消息开始后 30 秒熄灭）；明确 RACE START 或场次已 Started 且有圈数时，显示比赛已开始并熄灯；延迟信号亮橙色提示。真实消息优先于赛程倒计时，上游不提供逐灯遥测。无消息时仅按赛程时间计时，不推算暖胎圈。失联不重播已识别的比赛开始、结束、延迟状态。正式实时发车期间仍需验收。

全屏是覆盖页面的模态层，不自动调用浏览器 Fullscreen API。支持关闭与 ESC、焦点限制与恢复、滚动恢复。无自动音频。减少动态效果模式关闭动画，保留信号状态。Playground 仍是内联预览，不自动覆盖或锁滚动。

归零瞬间播放一次 1.8 秒的全屏视觉冲击：F1 白色光幕展开、FE 青色光幕与斜向框线扩散、WRC 绿色点阵光幕展开。仅从倒计时未到达切换为已到达时触发；打开已过期场次不会播放。关闭按钮保持可操作，减少动态效果模式不播放。

视觉修订：WRC 使用统一近黑设备面板、细分隔线和低亮度当地时钟；点阵为主要视觉。归零结果缩为短文案，手机保持单行，去除蓝色大字和双背景拼接。辅助来源说明压缩为一行。

Playground 的 previewFrameMs 参数复用同一套 CSS 归零动画：-1 为正常计时，0–1800 为暂停查看对应毫秒；建议检查 150、450、1200 毫秒。该参数只在 preview 模式生效，不更改计时、灯光、真实比赛状态或自动触发逻辑；减少动态效果偏好仍优先隐藏动画。
