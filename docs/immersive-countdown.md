# 沉浸式开赛倒计时

视觉使用扁平化设计：纯色灯板与信号、细边框、点阵数字。允许亮灯与点阵的少量柔和光晕；不使用渐变外壳、立体阴影或透视，不再画模拟车辆或赛道路线。

首页可见时，已确认场次距开始 0–120 秒（不包含归零）自动覆盖进入倒计时，适用于全部系列与首页视图。WRC 每站只允许时间最早的有效赛段自动触发：先按时间选第一段，再判断时间确认状态与触发窗口，不会在第一段过去后改为自动弹出后续段。忽略无效、估计、客户端待核验时间；有其他模态窗口时等待。多个场次选最近开赛者，不受首页筛选影响。

赛事详情时间线中，每个有有效且非估计时间的 WRC 赛段均提供手动倒计时按钮；待定赛段不虚构倒计时。

自动进入采用 1.25 秒的自下向上波浪转场，波浪离场后露出计时画面，关闭按钮始终可用。移动端粗指针设备尝试短震 35 毫秒；浏览器不支持、限制震动或没有用户激活时静默降级。减少动态效果模式不播放波浪也不震动。手动进入不触发该自动入场震动。

进入后保留该场次，不随首页下一场目标变化。sessionStorage 按赛事 ID 与 UTC 记录本标签页已展示场次，关闭、刷新后不重复弹出；存储不可用时使用内存记录。后台标签页不触发，回到首页可见时重新判断。离开首页不显示。

数字使用 NumberFlow 按位滚动，长倒计时拆分天、小时、分钟、秒；分钟与秒的十位限制为 5。最后五秒只显示秒。减少动态效果偏好由库默认尊重。

起跑装置仅在最后 30 分钟显示。F1 五列四灯位，下方两红灯成对亮起；FE 上下两排五灯，下排红灯，上排辅助绿灯。最后五秒逐列点亮红灯，归零熄灯。已删除暖胎圈时长推算、蓝色预启动程序和程序演示按钮，不再自动播放模拟发车程序。自动进入只发生在赛程开始前 2 分钟。

WRC 使用一行红色 13 方块像素显示（五行按 3、2、3、2、3 排列，以方块亮灭组成 0–9）：左边赛事当地时间 HH:mm:ss，右边仅在最后 60 秒显示两位秒数（60 至 00），60 秒前不显示。左右复用相同尺寸的数字图形，始终同字号、同基线；同一数字内部方块无间隙，左右数字组固定紧凑间距；右侧始终预留两个字位但不提前绘制，SVG 尺寸、字位、左右间距保持固定，出现、跨分钟与归零均不重新居中或缩放。去除边框、表头、单位、进度线、模拟表盘、状态栏和额外标题，仅保留关闭与 Playground 控件。归零显示 00；无障碍名称保留时区和计划发车含义。超过半小时仍使用通用长倒计时。

F1 实时状态来自 `/api/f1-start`，详见 `docs/data-flow.md`。明确 FORMATION LAP 消息显示辅助绿灯（消息开始后 30 秒熄灭）；明确 RACE START 或场次已 Started 且有圈数时，显示比赛已开始并熄灯；延迟信号亮橙色提示。真实消息优先于赛程倒计时，上游不提供逐灯遥测。无消息时仅按赛程时间计时，不推算暖胎圈。失联不重播已识别的比赛开始、结束、延迟状态。正式实时发车期间仍需验收。

全屏是覆盖页面的模态层，不自动调用浏览器 Fullscreen API。支持关闭与 ESC、焦点限制与恢复、滚动恢复。无自动音频。减少动态效果模式关闭动画，保留信号状态。Playground 仍是内联预览，不自动覆盖或锁滚动。

归零瞬间播放一次背景冲击：所有系列共用单个超宽主题色斜平行四边形，从左向右扫过钟表或灯板后层。F1、FE 持续 1600ms，WRC 持续 1800ms。仅从倒计时未到达切换为已到达时触发；打开已过期场次不会播放。关闭按钮保持可操作，减少动态效果模式不播放。

手机与桌面均使用同一个 SVG 比例缩放，左右数字等大，不换行。

Playground 的 previewFrameMs 参数复用同一套 CSS 归零动画：-1 为正常计时，0–900（WRC 至 1000）为暂停查看对应毫秒；建议检查 100、350、800 毫秒。该参数只在 preview 模式生效，不更改计时、灯光、真实比赛状态或自动触发逻辑；减少动态效果偏好仍优先隐藏动画。

逐帧验收修正（旧版探索，已废除）：曾将光幕峰值透明度降为 0.22；当前归零动效不使用全屏光幕。

WRC 仪式动效（旧版双帘方案，已废除）：曾以黑色双帘和主题色幕配合数字变色；当前改为与 F1/FE 一致的单个主题色斜平行四边形扫过背景，数字保持原位和原色。

左侧当地时间使用 WRC 主题蓝色，右侧倒计时为稍浅的蓝色。入场、脉冲、归零动效统一从 lib/series-theme.ts 读取主页赛事主题：F1 红、WRC 蓝、FE 绿；灯板实际红/绿/橙信号色独立保留。数字不再缩放或位移，仪式动效全部在背景层。目标或系列更换视为复位，不触发归零；剩余时间直接从同一时钟推导，避免旧状态残留一帧。

全屏容器使用固定视口高度并裁切屏外动效，同时锁定 html 与 body 滚动，退出时恢复原值。像素未点亮部分完全透明，避免归零主题色背景上出现黑色方块。


衔接：当地时钟的明暗在进入与退出最后五秒时均使用 400ms 过渡；取消数字本体反复增亮。归零数字颜色与背景共用完整收尾时间，动画卸载前已回到基础色，避免突然跳色。灯板测试的复位操作恢复五组红灯并关闭辅助绿灯、延迟提示。全屏焦点陷阱排除关闭 details 中不可见的控件。

F1 / FE 最后五秒衔接：时、分单位保留 DOM，以 500ms 宽度、间距和透明度过渡收拢，秒数字号同步变化。归零保留倒计时原位尺寸，以 350ms 淡出计时并延后 120ms 淡入开赛文字，避免整个计时块卸载造成纵向跳动。减少动态效果模式关闭这些过渡。

统一动效时间基准（2026-10-16）：lib/immersion-motion.ts 提供入场 1000ms、内容交接 420ms 起/500ms、脉冲 850ms 及各系列归零时长。入场缩短纯色停留；脉冲按目标 UTC 的整秒边界定位；归零以真实目标时刻（实时信号则以首次观察时刻）为起点。动画挂载时通过浏览器动画时钟补齐已过去的时间，随后由浏览器连续播放；过期归零不补播。取消独立归零清理定时器，统一由计时时钟判定动效结束。测试页逐帧时长复用同一配置，减少动态效果优先。

WRC 连续赛段（2026-10-16）：首页自动入场、首页手动入口和详情页赛段按钮共用 WrcCountdownSequence。打开时锁定选中的赛段；归零 1000ms 动效结束后等待 350ms，再选择同场赛事中 UTC 晚于当前赛段且仍在未来的最早已确认场次。跳过估计、无效时间、未经核验客户端上传，兼容事件 tentative 默认值与场次明确 false 覆盖。无下一场时保留 00，不循环、不抓取额外数据；关闭即取消监听，后续赛段不重新自动弹窗、不重复入场震动。切换时短暂显示赛段名称，并向辅助技术播报。此处表示赛程开始时间，不代表上一赛段实际完赛。

归零曲线强化（旧版双帘方案，已废除）：曾测试双帘过冲与全屏光幕衰减；当前由单个宽斜带完成扫动，不额外叠加双帘或色幕。

归零层次优化（旧版中心色幕方案，已废除）：曾测试主题色光幕与时钟回弹；当前时钟不缩放、不变色，视觉变化只发生在后层的宽斜带。

WRC 现场钟表外壳：StartClock 共用窄金属边框、深色内面板与顶部略向外伸的遮雨檐；手机端同比缩小边框和内距。数字字形、左右尺寸、时间逻辑、归零动效和连续赛段机制保持不变。外壳装饰不加入可访问名称。

手机景深（2026-10-16）：ClockParallax 在 HTTPS 触屏设备默认启用，不再显示效果开关；需要系统授权时，在首次轻触页面中请求 DeviceOrientationEvent 权限。首次有效读数校准握姿，角度映射支持屏幕旋转，最大上下 5 度/左右 6 度；共用一个传感器监听与 RAF 阻尼循环，不通过重复 CSS transition 跟随采样。外框、盖子、屏幕采用不同 Z 深度，修正先前平面梯形盖子的外观。隐藏页面及最后一个装置卸载时移除传感器监听；减少动态效果关闭透视。不上传动作数据，不影响赛程、归零或连续赛段。无硬件/不支持/拒绝权限时保留静态钟表。

景深实体修正：遮雨檐拆为独立顶板、前沿与左右侧挡片，前沿深度 28–42px；边框前平面位于 Z=12px，屏幕位于 Z=3px，玻璃层再前移 6px。保留祖先 preserve-3d，避免在 3D 容器使用 isolation/overflow/filter 等分组属性。像素组局部增加少量同色光晕，玻璃叠加极淡反射与扫描纹理；不对整组 3D 结构应用滤镜。

现场材质细节：玻璃亮斑位置随同一组倾斜角缓慢移动，屏幕边缘保留深色防水密封圈，框角使用低对比度槽形紧固件；不增加额外装饰文字。首页自动进入窗口统一由 AUTO_COUNTDOWN_WINDOW_MS=120000 控制，已过期场次仍不进入，WRC 后续赛段只在已打开的连续模式里推进。

陀螺仪处理优化：WRC/F1/FE 共用同一条默认启用的传感器流，使用与刷新率无关的指数阻尼、微小噪声死区和最大时间步长限制。停止移动后停止 RAF，后台停止采样并在恢复时重新校准；iOS 首次轻触请求一次系统权限，拒绝后不反复请求。移动中的变换不叠加 CSS 过渡；移除玻璃密集扫描纹理以减少旋转摩尔纹。灯板外壳 SVG 与前方 LED SVG 分别位于 Z=0/7px，保留三系列各自外形。浏览器对倾斜矢量边缘仍有抗锯齿能力限制，不保证所有手机完全无锯齿。

灯箱厚度：F1 五个独立灯柱、FE 整个面板补齐背壳与四周侧壁，深度 22–32px；前方 SVG 保留灯位，LED 层位于前方 7px。不添加隐藏的固定倾角：零角度为居中的正视图，转动手机或调节透视参数时显示箱体侧面。

安卓姿态兼容：不再用 pointer:coarse 判定传感器可用性；优先相对 deviceorientation，绝对事件仅作未收到相对数据时的回退，避免坐标系混用。测试总览显示真实接收状态、减少动态效果和无数据提示；不上传姿态。手动预览角度恢复为零后恢复传感器跟随。

连续赛段推进复用归零动画的总时长，动画结束并短暂保持后才切换下一赛段。

归零视觉方向：只保留单个主题色斜平行四边形，从左向右快速扫过背景；深色背景与钟表保持清楚，不叠加屏幕泛色、圆环或多道光线。总时长 WRC 1800ms、F1/FE 1600ms；支持减少动态效果。
